# План: адаптивность контактов в карточке /matrix + скрытие контактов при санкции на SEO-странице товара

## 1. Адаптивность контактов в карточке (ProductCard)

**Файл:** `src/components/shared/ProductCard.tsx:182-238`

Сейчас блок контактов — `flex items-center gap-2` без переноса, карточка жёстко ограничена (`w-72` в скроллере / 1 из 5 колонок grid), а базовый `Card` имеет `overflow-hidden` — три раскрытых контакта обрезаются.

Правки:
- Контейнеру (строка 183) добавить `flex-wrap` и вертикальный отступ: `flex flex-wrap items-center gap-x-2 gap-y-1` — контакты начинают переноситься на новые строки.
- Каждой раскрытой ссылке `<a>` (телефон/email/сайт): добавить `min-w-0`, у иконки `shrink-0`, текст завернуть в `<span className="break-all">` — длинные email и домены переносятся по символам, а не обрезаются.

Скрытые состояния (иконка + глазик) короткие — не трогаем, кроме `min-w-0` на обёртке для надёжности.

## 2. Скрытие контактов при санкции + сайт на /products/[id]

**Файл:** `src/app/(public)/products/[id]\page.tsx` (server component, всё на сервере, клиентский компонент не нужен)

- В Prisma-запрос (строка 38) в `company.select` добавить `website: true` и `billing: { select: { status: true } }`.
- Вычислить `const contactsBlocked = product.company.billing?.status === "HIDDEN";`
- Блок «Контакты» (строки 118–131):
  - при `contactsBlocked` — заглушка `<Lock /> Контакты скрыты` (как на `/suppliers/[id]`, строки 88–91);
  - иначе — телефон, email (как сейчас) + **сайт** ссылкой с иконкой `Globe` в стиле `/suppliers/[id]:100-104`.
- Импортировать `Globe`, `Lock` из lucide-react.

Обычным компаниям телефон/email/сайт остаются открытыми (решение пользователя); JSON-LD контакты не содержит — не трогаем.
